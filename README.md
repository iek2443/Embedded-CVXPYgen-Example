# Embedded-CVXPYgen-Example

This repository contains the Python script used to generate optimal, single-direction temperature control C code via **CVXPYgen**. The resulting C code is designed for embedded systems.

---

## 1. Project Goal and Mathematical Foundation

The fundamental goal of this project is two-fold:
1.  **Educational Study:** To demonstrate how **Convex Optimization** principles and **DPP (Disciplined Parametrized Programming)** rules can be applied to a practical control problem.
2.  **Embedded Preparation:** To produce C code that enables more efficient and optimal control compared to traditional methods on microcontrollers like STM32.

### Optimization Formulation:
The solver finds the optimal fan power ($\mathbf{u}$) by minimizing the total cost:

$$\min_{\mathbf{u}} \left( (\mathbf{x}_{\text{curr}} + k \cdot \mathbf{u} - \mathbf{x}_{\text{ref}})^2 + \lambda \cdot \mathbf{u}^2 \right)$$

Constraints: $0 \le \mathbf{u} \le 10.0$

---

## 2. Python Generation Script (`generate_solver.py`)

The core of the project is the Python script, which defines the problem and generates the C solver files into the **`embedded_cooling_solver`** directory.

### Key Inputs (Parameters):
| Parameter Name | Role | Meaning in Embedded System |
| :--- | :--- | :--- |
| **x_curr** | Current Temperature | Value read from Sensor |
| **x_ref** | Target Temperature | Reference Value |
| **k_gain** | Cooling Gain ($k$) | Constant defining cooling effectiveness (Negative value) |
| **lambda_cost**| Energy Cost ($\lambda$) | Constant defining penalty for control effort |

## 3. C Code Generation and Test Scenarios

The Python script verifies the solver's mathematical correctness against three distinct scenarios:

| Scenario | Input | Expected Result |
| :--- | :--- | :--- |
| **1 (Overheated)** | $30.0^\circ\text{C} \rightarrow 20.0^\circ\text{C}$ | High Positive $\mathbf{u}$ (Maximum cooling effort) |
| **2 (Slightly Warm)** | $23.0^\circ\text{C} \rightarrow 20.0^\circ\text{C}$ | Low Positive $\mathbf{u}$ (Precise cooling) |
| **3 (At Target)** | $20.0^\circ\text{C} \rightarrow 20.0^\circ\text{C}$ | $\mathbf{u} = 0.0$ (Fan is OFF) |
